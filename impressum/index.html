Impressum und Datenschutz

Gilt für alle Seiten unter bingerminger.github.io: die Startseite, die Projektseiten von Energietracker, Cat-O-Fit, update-all, RookyCMS und Sternenflunk sowie deren Demos.

Wer dahintersteht

Alle Projekte sind private Open-Source-Projekte ohne Gewinnabsicht von Bingerminger auf GitHub, entwickelt und gepflegt in der Freizeit. Keine Firma, keine Werbung, nichts zu kaufen. Der Code steht jeweils unter der Lizenz, die im Repository angegeben ist.

Kontakt

Kontakt läuft über GitHub: Fragen, Ideen und Fehler als Issue oder Diskussion im Repository des jeweiligen Projekts, Sicherheitslücken vertraulich über „Security → Report a vulnerability“ dort. Übersicht: github.com/Bingerminger.

Datenschutz auf diesen Seiten

  • Keine Cookies, kein Tracking, keine Auswertung von Besuchen.
  • Nichts von fremden Servern: Schriften, Bilder und Skripte liegen auf diesen Seiten selbst. Einzige Ausnahme ist die Demo von Cat-O-Fit: Sie fragt das Wetter für die Trainingsplanung bei Open-Meteo ab (api.open-meteo.com). Dabei erhält Open-Meteo deine IP-Adresse; es gelten dort deren Regeln.
  • Im Browser: Die Demos laufen ganz im Browser mit erfundenen Beispieldaten und speichern diese samt Einstellungen im Speicher deines Browsers (localStorage). Manche Seiten merken sich dort auch die gewählte Darstellung. Das bleibt auf deinem Gerät; löschen kannst du es in den Einstellungen deines Browsers.
  • Hoster ist GitHub Pages (GitHub, Inc.). Laut GitHub wird beim Aufruf einer Seite die IP-Adresse zur Sicherheit protokolliert, auch ohne Anmeldung: Datenerhebung bei GitHub Pages, Datenschutzerklärung von GitHub.
  • Links nach außen führen zu GitHub, zu Home Assistant, zu Open-Meteo und zu buymeacoffee. Erst wenn du sie anklickst, gelten dort deren Regeln.

Verantwortlich für diese Seiten ist der Anbieter aus dem Impressum.
